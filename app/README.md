# 汇芯智能体中台 · 本机可用版 0.2.0

唯一产品入口：应用程序中的「汇芯智能体中台」。39261 为桌面进程内部本机通信端口，不提供普通浏览器产品入口。

打开「应用程序 → 汇芯智能体中台」，使用独立桌面窗口。桌面应用启动和管理本机服务。先打开 T3 Code，确保所需提供方已配置。
运行环境为 macOS 与 Python 3 标准库，无需安装前端依赖、数据库服务或代理。

## 已实现

- 星尘版布局方向的中文工作台，六类业务导航、搜索、明暗主题。
- Codex、Antigravity、WorkBuddy 的真实任务提交与模型选择。
- 对话、执行状态和后续追问，从 T3 实际会话同步。
- 每个任务独立产物目录、真实文件列表、查看与下载。
- 本地 SQLite 保存任务索引，重启保留任务和文件。
- 本机绑定、Host/Origin 检查、会话 Cookie、请求令牌和文件路径范围检查。

## 适用范围

这是单公司、本机使用版本。任务实际由已安装的 T3 执行，会消耗对应账号额度。
业务分类和起步提示已经可用；专业 Skill 的自动选择、输入资料上传和完整业务验收流程尚未实现。
审批、固定选项问题与中断任务，需要在 T3 桌面应用中处理；页面提供「打开 T3」入口。
页面按约 3.5 秒间隔同步状态，不展示虚构的阶段、额度和进度百分比。

## 数据与分发

业务数据默认位于 `~/.local/share/huixin-agent-hub`，包括 `hub.sqlite` 和 `workspace/tasks/`。
访问密钥由本机 T3 运行环境管理，不包含在应用源代码中。
交付文件可在页面打开；HTML、SVG 等主动内容作为文本提供，避免以工作台身份执行其中的脚本。
文件列表展示上限为 100 个，单文件查看上限为 200 MB。

此目录不是已完成的公共开源发布包。公开发布前还需拆分个人使用记录、截图、品牌配置和本机适配路径，补齐许可及分发验证。
界面设计参考：https://github.com/zds-xiaoxin/xiaoxin-t3code
执行后端：https://github.com/pingdotgg/t3code

## 桌面应用构建

运行 `zsh app/build-desktop.sh` 生成本地 `.app`。当前仅在此 Mac 上验证，使用本地 ad-hoc 签名；客户分发的 Developer ID 签名、公证和其他系统版本测试尚未完成。
